# Proposta Comercial Executiva · 4E Imóveis

Este é um projeto independente e leve desenvolvido em Next.js (React), contendo exclusivamente a **Apresentação Executiva da 4E Imóveis**.

---

## Como Hospedar na Vercel (Em menos de 2 minutos)

Como o projeto é 100% estático e não depende de banco de dados nem de variáveis de ambiente:

### Opção 1: Pelo site da Vercel (Recomendado via GitHub)
1. Crie um repositório no GitHub (ex: `proposta-4eimoveis`) e envie esta pasta:
   ```bash
   git init
   git add .
   git commit -m "feat: proposta executiva 4e imoveis"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/proposta-4eimoveis.git
   git push -u origin main
   ```
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New Project"**.
3. Importe o repositório `proposta-4eimoveis`.
4. Clique em **Deploy** (sem precisar configurar nenhuma variável).
5. Em segundos, você terá uma URL pública e rápida pronta para compartilhar com o proprietário.

### Opção 2: Pelo Terminal (Vercel CLI)
Caso tenha a Vercel CLI instalada:
```bash
npx vercel
```
Siga as confirmações padrão para colocar no ar imediatamente.

---

## Como Rodar Localmente

```bash
npm install
npm run dev
```
Acesse `http://localhost:3000` no seu navegador.
